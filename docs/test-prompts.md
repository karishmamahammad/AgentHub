# Demo test prompts

Use these in a private Discord test channel after connecting the agent.

1. `@AgentHub Explain what this repository does and list its main folders.`
2. `@AgentHub Turn this feature request into a task plan with dependencies: add a user profile page.`
3. `@AgentHub Review this workspace for obvious bugs. Do not modify files yet; report findings first.`
4. `@AgentHub Propose a small input-validation change. Explain the plan and wait for approval before editing.`
5. `@AgentHub Summarize this discussion into decisions, action items, blockers, and open questions.`
